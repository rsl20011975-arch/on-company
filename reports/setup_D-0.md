## 지시서와 달랐던 점
- **앱 이름이 `AI ON`** (지시서는 `ON Company`). 사람이 잘못 입력했고 그대로 진행하기로 함.
- 앱이 처음에 **광고(마케팅 API) 사용 사례**로 만들어져 있었고, Instagram 사용 사례는 나중에 붙였다.
- **비즈니스 포트폴리오가 이미 `ai.sajang.on` 으로 연결**되어 있음 (지시서는 건너뛰기).
- 권한 `manage_messages` 가 "필수 권한 추가" 버튼으로 함께 붙음 (지시서 4개 외 1개, 사용 안 함).
- 토큰 생성 팝업이 인스타 로그인 직후 홈으로 가버려 허용 화면이 한 번 건너뛰어짐. 같은 버튼을 다시 눌러 해결.
- **토큰 값이 사람의 채팅 입력으로 PC 세션 대화 기록에 남음.** 파일·커밋에는 없음(`.env` 는 git 제외 확인). 필요하면 토큰 재발급으로 교체.

## 프로필 확인 (사람이 보낸 프로필 편집 스크린샷 기준, 22:50경)
- 프로필 사진: 적용됨(ON 로고). 소개글: 입력됨, 66/150자(지시서 4줄 전체인지는 미확인).
- **AI 생성 프로필 라벨:** 스크린샷 시점엔 꺼져 있었고, 사람이 켜고 제출했다고 알려옴(화면 재확인 안 함).
- **이름:** 화면에 `ON` 으로 표시. 지시서 값 `AI 사장 온 | AI 활용법` 은 사람이 계정 센터에서 바꾸도록 안내함, 변경 여부 미확인.
- **링크:** 웹 화면에선 수정 불가(모바일 앱 전용). 입력 여부 미확인.
- **Facebook 연결:** 지시서는 '하지 않기'인데 `Ai.sajang.On` 이 이미 연결되어 있음(비즈니스 포트폴리오 생성 때 딸려 온 것으로 추정, 원인 미확인). 연결 팝업은 '나중에 하기'로 닫음. 끊을지는 사장실 판단 필요.

- **2단계 인증:** 사람이 완료했다고 알려옴(인증 앱 방식인지, 화면 재확인은 안 함).
