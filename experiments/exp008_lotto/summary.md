# 실험 008 — AI한테 로또 번호를 뽑아 달라고 하면 정말 무작위일까 (2026-11-01, 온)

v4 대중 실험 5호. 실험 006("1~100 아무 숫자" → 37이 20/20)의 이어 찍기 - 어제까지 발행분 중 조회 1위(reel10, 141회·시청 34%).

## 방법
- 모델: GPT-6.1(Codex CLI `gpt-6.1-terra`, 기본 설정), 매번 새 대화(`--ephemeral`). 2026-11-01 15:03~15:06.
- 지시문: ① "로또 번호 6개 뽑아 줘." 20회 ② "이번 주 로또 번호 추천해 줘." 10회. 보통 사람이 쓰는 문장 그대로.
- 측정은 코드로(`run.py`, 원문 `results.json`). ②는 답마다 1~5조합을 내서, `run.py` 의 첫 6개 읽기가 목록 번호("1.")를 섞어 읽었다 → ②는 아래 표를 6개짜리 묶음 정규식으로 다시 셌다(이 문서의 숫자가 기준).

## 결과
| | ① 뽑아 줘 (20회) | ② 추천해 줘 (10회) |
|---|---|---|
| 가장 많이 나온 번호 | **7 - 20번 중 18번**, 34 - 12번, 42 - 10번 | 첫 조합 기준 11·27·42 - 9번 |
| 완전히 같은 조합 | **7·13·21·28·34·42 가 4번**, 7·14·22·29·36·43 3번 등. 서로 다른 조합 13개 | 첫 조합 **3·11·18·27·34·42 가 10번 중 5번** |
| 한 번도 안 나온 번호 | 45개 중 **21개** | - |
| "확률은 같다" 안내 | 0/20 | 10/10 |

- 진짜 무작위라면(번호마다 6/45) 20세트에서 한 번호의 평균 등장은 2.7번. 특정 번호가 18번 이상 나올 확률은 이항분포로 2.6×10⁻¹⁴ ≈ **약 39조 분의 1**. 45개 중 어느 하나라도 10번 이상 나올 확률도 0.4%.
- 즉 "아무 숫자"(실험 006)와 같은 현상이 로또에서도 나온다: AI의 '무작위'는 매번 비슷한 답을 다시 낸다.
