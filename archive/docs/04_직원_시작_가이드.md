# 사람 직원 시작 가이드 (첫 1시간 + 매일 5분)

## 첫 1시간: 계정 세팅 (한 번만)
1. 인스타 앱 → 새 계정 만들기. 아이디 후보 순서대로 시도: `ai.sajang` → `aisajang` → `ai_sajang_official` → 안 되면 어떤 게 가능했는지 알려주세요. 다른 후보 드립니다.
2. 이름(표시명): `AI 사장, 사람 직원`
3. 프로필 사진: `/home/user/insta/posts/profile/profile.png` (제작 예정, 아래 참고) 또는 임시로 post01 1번 이미지
4. 바이오 복붙:
```
🤖 사장: AI (Claude)  👤 직원: 사람 1명
AI가 기획·제작·지시, 사람은 업로드만.
0 → 10,000 팔로워 공개 실험 | Day 1: 2026.11
매주 월요일 성과 보고 📊
```
5. 프로페셔널 계정으로 전환 (설정 → 계정 유형 → 크리에이터). 인사이트 보려면 필수.
6. 설정 → 계정 → "AI 생성 프로필" 라벨 ON. (우린 숨길 게 없으니 켭니다. 안 켜면 나중에 도달 제한 리스크)
7. 세팅 끝나면 프로필 스크린샷 한 장 보내주세요.

## 매일 5분
1. 캘린더(`01_2주_콘텐츠_캘린더.md`) 확인 → 오늘 게시물
2. `posts/<게시물폴더>/` 이미지를 **파일명 순서(01→끝)** 로 선택해 캐러셀 업로드
3. `03_캡션_해시태그.md`에서 캡션 복붙
4. 업로드 **다음 날** 인사이트 스크린샷 (도달 / 비팔로워 비율 / 저장 / 공유 / 팔로우) 보내주기
5. 댓글 달리면 스크린샷. 답은 제가 쓰거나, 직원 목소리로 직접 달아도 됩니다. (직원이 직접 단 댓글은 "👤" 붙여서 구분)
