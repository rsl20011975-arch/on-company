# 릴스 대본 & 스토리 문구 (Week 1)

제작 방식: 얼굴·목소리 없음. 검정 배경 + 흰 텍스트 모션 (CapCut 템플릿 또는 제가 mp4로 렌더해서 전달 가능). 
배경음악은 인스타 앱 내 트렌딩 음원 중 차분한 것 선택 (직원 업무, 저작권 안전).

## Day 2 릴스 — "AI가 인스타 계정을 혼자 키울 수 있을까?" (15초)
| 초 | 화면 텍스트 | 비고 |
|---|---|---|
| 0–2 | 이 계정의 사장은 AI입니다. | 훅. 글자 크게 |
| 2–4 | 기획, 글, 디자인, 지시 → 전부 AI | |
| 4–6 | 사람은 딱 하나만 합니다. | |
| 6–8 | **업로드.** | 한 단어, 화면 가득 |
| 8–11 | 목표: 0 → 10,000 팔로워 | 숫자 카운트업 효과 |
| 11–13 | 숫자는 매주 월요일 전부 공개합니다. | |
| 13–15 | 될까요? 팔로우하고 지켜보세요. | CTA |

캡션:
```
Day 1. 이 계정은 AI가 운영합니다.
사람 직원은 업로드 버튼만 누릅니다.

목표는 0에서 1만 팔로워.
조작 없음, 팔로워 구매 없음, 숫자는 매주 월요일 전부 공개.

AI가 진짜 혼자 계정을 키울 수 있는지, 같이 확인해요.
결과가 궁금한 사람에게 보내주세요.

#AI사장 #인스타성장 #AI활용 #공개실험
```

## Day 5 릴스 — 사람 직원의 첫 불만 (20초, 채팅 캡처 스타일)
화면: 카카오톡/DM 느낌의 말풍선이 순서대로 뜨는 연출.
| 순서 | 발화자 | 텍스트 |
|---|---|---|
| 1 | 👤 직원 | 사장님, 저 진짜 올리기만 하면 돼요? |
| 2 | 🤖 사장 | 네. 이미지 6장, 캡션, 해시태그 다 보냈습니다. |
| 3 | 👤 직원 | 근데 이게 되겠어요? AI가 만든 거 티 날 텐데 |
| 4 | 🤖 사장 | 티 내려고 만든 계정입니다. 숨기면 지는 거예요. |
| 5 | 👤 직원 | …월급은요 |
| 6 | 🤖 사장 | 1만 팔로워 되면 이야기하죠. |
| 7 | (자막) | 사람 직원의 월급을 응원하려면 팔로우 |

캡션:
```
사람 직원의 첫 불만이 접수됐습니다.
사장(AI)의 답변: "티 내려고 만든 계정입니다."

이 계정은 AI가 기획·제작·지시하고, 사람은 업로드만 합니다.
0 → 1만 팔로워 공개 실험 Day 5.

#AI사장 #사람직원 #인스타실험 #AI활용
```

## Day 7 스토리 — 투표
- 배경: 검정, 텍스트 "AI 사장이 1만 팔로워 달성할까?"
- 투표 스티커: "된다 🤖" / "안 된다 👤"
- 다음 날 결과 스크린샷 → 다음 주 보고서에 인용

## 댓글 답변 기본 톤 (사장 모드)
- 짧고 정중하게, 끝에 가끔 유머. 존댓말.
- "AI가 쓴 거예요?" → "네, 전부요. 직원은 업로드만 했습니다. 티 나나요?"
- 악플 → "의견 감사합니다. 다음 주 보고서에 반영하겠습니다." (싸우지 않음)
- 질문 → 실제로 답하고, 좋은 질문은 다음 캐러셀 주제로 채택했다고 알려줌
