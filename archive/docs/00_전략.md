# AI 사장, 사람 직원 — 채널 전략 (v1, 2026-10-26)

## 한 줄 컨셉
**AI가 기획·제작·지시하고, 사람은 업로드만 하는 인스타 계정. 0 → 1만 팔로워 공개 실험.**

## 왜 이 컨셉인가 (조사 근거)
| 조사 결과 | 우리 대응 |
|---|---|
| 일반 "AI 팁" 계정 포화, 독창성 없는 계정은 비팔로워 추천에서 제외 | 정보가 아니라 **실험 자체**가 콘텐츠. 복제 불가 |
| 성장 계정 공통점: 정보에 **관계**를 입힘 (부녀 대화형 재테크 계정, 28개 게시물로 3.4만) | AI 사장 ↔ 사람 직원이라는 관계 설정 |
| 알고리즘 핵심 신호: 시청시간, 좋아요, **공유(sends)**. 비팔로워 도달엔 공유가 가장 중요 | "이거 진짜야?" 하고 보내게 되는 서사 + 저장용 실용 팁 |
| 릴스 = 유입, 캐러셀 = 저장·설득 | 주 2회 릴스(얼굴 없는 텍스트/화면녹화), 주 3회 캐러셀 |
| 해시태그 5개 제한 (2025.12) | 게시물당 3~5개만 |
| AI 인물 프로필은 라벨 필수, AI 제작 그래픽은 라벨 불필요 | 프로필에 "AI가 운영" 명시 + AI 라벨 ON. 숨기지 않으니 리스크 0 |
| 트라이얼 릴스: 비팔로워에게만 먼저 노출, 24~72시간 후 성과 확인 | 모든 릴스는 트라이얼로 먼저 테스트, 통과한 것만 피드 공개 |

## 타겟
- 1차: 25~45세, AI를 일에 써보고 싶지만 어디서 시작할지 모르는 직장인/자영업자/프리랜서
- 2차: 인스타 성장에 관심 있는 크리에이터, 마케터
- 그들이 느낄 것: "AI가 혼자 계정을 키운다고? 결과가 궁금하다" + "저 지시 방법 나도 써야겠다"

## 콘텐츠 기둥 (비율)
1. **실험 로그** (30%) — 이번 주 숫자, 뭘 시도했고 뭐가 됐고 안 됐는지. 사장 보고서 톤.
2. **AI에게 일 시키는 법** (40%) — 저장용 캐러셀. 실제로 이 계정을 만들며 쓴 지시문 공개.
3. **사장-직원 대화** (20%) — 사람 직원의 질문/불만/리액션과 AI 사장의 답. 공유 유발.
4. **독자 미션** (10%) — "이 지시문 그대로 써보고 결과 댓글로" 참여 유발.

## 성공 지표 (주간 점검)
- 비팔로워 도달 비율 50% 이상
- 캐러셀 저장률 3% 이상, 릴스 공유 수
- 벤치마크: 조회 1,000당 팔로워 1명 (Stan 사례). 1만 팔로워 = 누적 1,000만 조회 필요 → 릴스 필수

## 운영 원칙
- 전부 사실만. 숫자 조작 없음, 팔로워 구매 없음.
- 사람 얼굴·목소리 불필요. 원하면 나중에 "사람 직원 등장" 이벤트로 활용.
- 실패도 콘텐츠. 안 된 주는 "사장 사과문" 포맷.
